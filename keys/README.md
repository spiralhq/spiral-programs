# Program keypairs

This directory holds the private keypair files for the two Solana programs
declared in this workspace:

- `organization-keypair.json` -> `2JWb4r1LgykRNocsxVgfhysLtFtgjWvMRzceBDX79WCw`
  (matches `declare_id!` in `programs/organization/src/lib.rs` and
  `[programs.localnet].organization` in `Anchor.toml`)
- `film-keypair.json` -> `6MK8C7frTETvrmM5dhN6jkUyXdxcMAfTjKkhG1Y7Pcbu`
  (matches `declare_id!` in `programs/film/src/lib.rs` and
  `[programs.localnet].film` in `Anchor.toml`)

These are the **only** copies of the private keys that can deploy upgrades
to those exact addresses. `anchor build` normally writes copies of these
same files to `target/deploy/`, but `target/` is gitignored and gets wiped
by `cargo clean`, a fresh clone, or a CI runner rebuilding from scratch. If
`target/deploy/*-keypair.json` is lost and regenerated by a fresh
`anchor build`, the new keypairs will have **different public keys** that no
longer match the Program IDs already committed in source — and you cannot
deploy to an address you don't hold the private key for. This `keys/`
directory exists so the real keypairs survive independently of `target/`.

## Important: these files are still secrets

The JSON files in this directory (`keys/*.json`) are gitignored on purpose.
They are **not** committed to git, and this file (`keys/README.md`) is
committed only to explain that fact and carry the backup instructions below.
Never remove `keys/*.json` from `.gitignore` or commit the keypair files
themselves.

## Action required before deploying to Devnet

Before these programs are deployed to Devnet and the Program IDs become
public / referenced elsewhere, **back up both files** to durable, secure
storage — e.g. a password manager or encrypted storage — outside of this
git working copy and outside of `target/`.

Once a program has been deployed to an address other people or services
depend on, losing the corresponding keypair means that address can never be
redeployed (upgraded) to again. Treat these files with the same care as any
other private key material.
